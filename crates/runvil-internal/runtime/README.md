# Engine executor

This crate is the Engine's executor: it runs a parsed prompt as a deterministic state machine. Each model round, Pack render, Pack tool call, `store` operation, and timer leaves the executor as an effect for the Harness to perform and answer, and every boundary is reported as an event. A run ends with its result: the final text, or the error that ended it, where a cancel is the error whose code is `Canceled`. Adhoc tool calls, `GetDynamicTools` calls, and refused discovery calls run inside the Engine and are reported only as events. The Engine makes each run an empty store of its own, in memory and outside the filesystem the run's tool calls work in, and the store is reached only through the view of each `store` effect. Given the same prompt, arguments, and `RunParams` inputs, its seed and start time included, and the same answers delivered in the same order at the same steps, a run produces the same effects, events, and result.
